# A Universe for You

使用 Three.js 制作的交互式生日礼物，作者 Bowyh。

打开网页后点击开始。音乐在首次交互后播放。添加 `?to=姓名` 可更换收礼人。

包含星空、涂抹黑夜、三种花朵、北京时间、粒子倒计时、旋转蛋糕和生日祝福。麦克风需要 HTTPS；拒绝授权时可长按按钮吹灭蜡烛。微信内浏览器若限制音频或麦克风，可通过右上角菜单选择在系统浏览器中打开。

本地预览：在本目录运行 `npx --yes http-server .`。部署使用 GitHub Pages，从 main 分支根目录发布。

Three.js 使用 MIT 许可证。音乐为用户提供的《打上花火（Pianominion版）》MP3。花朵与蛋糕贴图为项目制作素材。
